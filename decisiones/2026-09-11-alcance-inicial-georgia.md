# Decisión de alcance inicial — Georgia

Fecha: 2026-09-11
Estado: aprobado para iniciar investigación

## Decisiones

- Georgia es el país del Cáucaso, no el estado de Georgia en Estados Unidos.
- Se mantiene como referencia metodológica el estudio de Rumanía.
- Los productos objetivo por defecto son Sensa®, Silestone® y Dekton®.
- La investigación se hará en georgiano, ruso e inglés.
- El proyecto tendrá dos segmentos comerciales principales: partners de proyectos para contacto a puerta fría y distribuidores.
- Se incorpora una vía híbrida para marmolistas/procesadores, con atención especial a quienes compren o trabajen con competidores.
- Se realizará un estudio independiente de competencia.
- La aplicación web se pospone hasta validar taxonomía, modelo de datos, scores y una primera muestra.

## Criterio de evidencia

La presencia de una marca en una web no demuestra que exista compra directa, distribución, exclusividad o relación contractual. Cada afirmación debe conservar URL, idioma, fecha de consulta y nivel de confianza.

## Siguiente decisión prevista

Tras el primer bloque de descubrimiento se revisará si las ciudades y regiones iniciales justifican mantener Tbilisi, Batumi, Kutaisi, Rustavi y otras zonas que aparezcan con evidencia comercial.
